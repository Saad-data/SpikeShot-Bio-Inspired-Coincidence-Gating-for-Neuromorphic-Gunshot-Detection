2. DATA ENCODING
================================================================================

2.1 CGTC 128-bin (Coincidence-Gated Temporal Contrast)
------------------------------------------------------
Pipeline:
  1. Mel spectrogram: 128 bins, n_fft=1024, hop=64, 22.05 kHz
  2. Log power
  3. Temporal contrast: frame-to-frame difference
  4. Adaptive threshold: mean + 1.0×std
  5. Coincidence gate: spike if ≥48% of mel bands exceed threshold

Parameters:
  n_mels:              128
  n_fft:               1024
  hop_length:          64 (~2.9 ms per frame)
  coincidence_threshold: 0.48
  contrast_multiplier: 1.0

Output: 1D spike train, ~258 timesteps per 0.75s clip

2.2 Window Configuration
------------------------
- Clip duration: 0.75s (16,537 samples @ 22.05 kHz)
- Gunshot window: PRE_OFFSET=0.2s, POST_OFFSET=0.55s (centered on timestamp)
- Non-gunshot: energy-peak centered, same 0.75s

7.3 Key Findings
----------------
- Event-centric encoding is essential: +39% vs energy-peak, +16% vs windowed 4s
- All three architectures perform similarly with correct encoding (~94–95%)
- MILSNN: best accuracy (94.98%) and strong FNR (8.20%)
- HierarchicalSNN and TemporalConvSNN: lowest FPR (1.58%, fewest false alarms)
- CGTC 128-bin with threshold=0.48 is optimal
- Window size 0.75s captures full gunshot event

7.4 Multi-seed reporting (mean ± std)
-------------------------------------
Results can be reported over multiple random seeds for stability. Train with
--seeds then run eval with the same --seeds to aggregate and report mean ± std.

  Train (multi-seed):
    python main.py train --seeds 42,43,44,45,46
  Output: outputs/snn_top3_results/seed_42/, seed_43/, ... (one set of checkpoints per seed).

  Eval (aggregate over seeds):
    python main.py eval --seeds 42,43,44,45,46
  Output: encode_comparison/test_eval_on_split/eval_results.txt and eval_results.json
  with "Aggregated over N seeds: mean ± std" for Accuracy, F1, FPR, FNR, ROC-AUC.
  JSON includes "by_seed" (per-seed metrics) and "aggregated" (mean/std per metric).

  Full pipeline with multi-seed:
    python main.py all --seeds 42,43,44,45,46
